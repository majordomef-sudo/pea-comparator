# Memory Recall Hook

Injects `state/memory_context.md` (recent PROCEDURAL lessons + EPISODIC sessions,
regenerated by `scripts/memory_context_recall.py`) into the session bootstrap via
`context.bootstrapFiles`.

Regenerate the file with:

```bash
python3 scripts/memory_context_recall.py --write
```
