## Leçons outils (2026-09-20, à retenir)
- **Heredocs dans exec** : le wrapper casse les scripts contenant `\n` interprété, regex avec flags, ou certaines combinaisons de quotes. Solutions fiables : écrire le fichier via `python3 - <<'PYEOF'` (simple, marche), ou `node -e 'const fs=require("fs"); fs.writeFileSync(...)'` (String.raw), ou printf par lignes. Éviter les chaînes avec `\n` littéral dans la commande.
- **Puppeteer core dispo** : /tmp/node_modules/puppeteer-core + executablePath /usr/bin/chromium-browser (headless). Le browser tool OpenClaw timeout parfois au démarrage ; le fallback CLI puppeteer fonctionne très bien.
- `git add -A` englobe hors-scope (logs VPN, .git imbriqués) — préférer `git add <fichiers ciblés>`.
- Sauvegardes de config nginx : JAMAIS dans sites-enabled/ (nginx charge tout le dossier) — les mettre dans /root/backups/nginx/.
- Source du site : web/pea-comparator/ (git), prod = /var/www/html (copie, sudo pour écrire).
