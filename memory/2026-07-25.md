## Audit calculateurs Alfred Invest (06:26-07:40)
Le nom du site est "Alfred Invest" (pas "Alfred Finance"). 5+ calculateurs dans `web/pea-comparator/`.

### Bugs trouvés et corrigés dans `script.min.js` :
1. **Fiscalité AV/PEA erronée** — bloc `if(y>=5)` vide (commentaire seulement), taxe appliquée qu'à la fin
   - Fix : `simulate()` prend `applyAfterYears`, AV taxée à 30% avant 8 ans, 24,7% après, allowance 4600€
2. **PEA simulé avec 0,2% frais annuels** → passé à 0 (Trade Republic = 0 frais de garde)
3. **Frais : soustraction linéaire** `(rate-fee)/12` → géométrique `((1+rate)/(1+fee))-1`
4. **halfTarget trompeur** : 50% des apports au lieu de 50% du capital final → corrigé avec formule exacte
5. **FIRE : inflation ignorée** + capitalisation annuelle au lieu de mensuelle → ajout champ inflation 2%, rendement réel
6. **Cache-buster manquant** : `script.js` chargeait `script.min.js` sans version → ajout `?v=Date.now()`

### Dans `calc_functions.js` :
- **Catchup** : taux annuel/12 approximatif → taux mensuel correct `(1+rate)^(1/12)-1`

### Fausse alerte :
- `fire-save` et `fire-return` existent bien dans l'HTML (lignes 310-311)

### Problème rencontré avec Eric :
- Eric voyait 75 000€ au lieu de 900 000€ sur le FIRE car le cache navigateur servait l'ancienne version de `script.min.js`
- Fix : cache-buster ajouté dans `script.js`

### Fichiers patchés :
- `web/pea-comparator/script.min.js` — 6 correctifs
- `web/pea-comparator/calc_functions.js` — 1 correctif
- `web/pea-comparator/index.html` — ajout champ inflation
- `web/pea-comparator/script.js` — cache-buster
- Backups : `*.bak` pour chaque fichier modifié

  - 🇺🇸 S&P 500 (top 5)
  - 🌏 Émergents (top 5)
  - 🇪🇺 Europe (top 5)
  - 🇫🇷 CAC 40 (top 5)
  - 🇯🇵 Japon (top 5)
  - 💻 Nasdaq / Tech (top 5)
  - 🥇 Or / Matières (top 5)
  - 📊 Obligations (top 5)
  - 💰 Meilleurs frais (tous, tri TER asc)
  - 📈 Meilleure perf 5A (tous, tri perf5 desc)
- **Classement par score composite** : frais bas (×3) + perf élevée (×2) + stress faible (×1), normalisé 0-100
- Clic sur un ETF → recherche dans le tableau + scroll

### Problème de placement
- Section Top ETFs était placée APRÈS le tableau 429 ETF (tout en bas) → Eric ne voyait rien
