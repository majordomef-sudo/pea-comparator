## LLM Cost Tracking — Réparation complète
### Problème
- Le rapport `llm_cost_report.py` lisait `llm_costs.jsonl` qui n'existait pas → $0.0000
- Aucun script ne loggait les coûts des appels LLM

### Solution
1. **`llm_cost_report.py`** — Rewrite pour utiliser l'API OpenRouter (`/api/v1/auth/key`) qui donne les vraies données de consommation
   - Coût réel trouvé : **~$90/mois** (cumulé: $90.10)
   - Backup conservé en `.bak`

2. **`model_router.py`** — Ajout de `log_llm_call(model, prompt_tokens, completion_tokens)` avec :
   - Prix hardcodés par modèle (DeepSeek Flash: $0.15/$0.60, Pro: $2/$8, Gemma-4: gratuit)
   - Log vers `~/output/logs/llm_costs.jsonl` (format JSONL, chaque ligne = 1 appel)
   - Création auto du répertoire si nécessaire

3. **Hooks scripts :**
   - `nocturne_nudge.py` — log après réponse API (import + `log_llm_call()`)
   - `blog_writer.py` — log après réponse API (import + `log_llm_call()`)

### Limitation
- ~90% des appels passent par OpenClaw gateway (non interceptable en Python)
- Ces coûts sont récupérés via l'aggrégat OpenRouter API
- Seuls les appels directs (nocturne_nudge, blog_writer) sont loggés ligne par ligne

### Leçons
- Un fichier de log qui n'est jamais écrit donne toujours $0 — toujours hooker le writer en même temps que le reader
- L'API OpenRouter `GET /api/v1/auth/key` retourne `data.usage` fiable
- Les modèles Gemma-4 (free) coûtent $0 — important pour le routing économique
